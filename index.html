Политика конфиденциальности Auto Reply

Дата вступления в силу: 28 октября 2026 г.

Auto Reply — приложение для профессиональных аккаунтов Instagram, которое обрабатывает комментарии к публикациям по заданным владельцем правилам и может отправлять ответ на комментарий или личный ответ через официальные API Meta.

Какие данные обрабатываются

При работе приложения могут обрабатываться идентификатор комментария, идентификатор медиафайла, текст комментария, имя пользователя, дата и время события, а также технические статусы отправки ответа. Данные используются только для выполнения настроенного владельцем аккаунта сценария ответа и ведения журналов работы.

Как используются данные

Данные не продаются и не передаются третьим лицам в рекламных целях. Они используются только для обработки комментария, отправки настроенного ответа через API Meta, предотвращения повторной обработки событий и устранения ошибок.

Хранение и защита

Данные хранятся в базе данных, контролируемой владельцем приложения, в течение срока, необходимого для работы и диагностики сервиса. Access token и иные секреты доступа не сохраняются в журналах событий.

Удаление данных

Чтобы запросить удаление связанных с вами данных, напишите на host1ik1er@gmail.com с темой Auto Reply data deletion request и укажите ваш Instagram username и, если известен, идентификатор комментария. Запрос будет рассмотрен в разумный срок, если сохранение данных не требуется по закону.
